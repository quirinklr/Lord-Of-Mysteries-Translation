# LOTM English Patch 1.0.2

Supported game build: `1.2018737.2044036`

## Install

1. Download the ZIP from GitHub Releases and extract it completely.
2. Close the game and launcher.
3. Run `Install.cmd`.
4. Approve the Windows administrator prompt.
5. Start the game normally.

The installer detects the default Bilibili game folder. If detection fails, select the `C7` folder when prompted.

## Maintenance

- `Update.cmd` updates an existing installation.
- `Verify.cmd` checks every installed file.
- `Uninstall.cmd` restores the original PAK block and files.

The installer refuses unsupported game builds, modified target blocks, invalid package files, and changes while the game is running.

End users do not need Python, .NET, Git, or third-party patching tools.
